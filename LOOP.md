## Bugs Found and Fixed

See the iteration log above for full context. A few were confirmed at review
to be the same root cause:

1. **Auth endpoints blocked by apiKeyMiddleware** (`/auth/register`,
   `/auth/login`, `/auth/nonce`). Fixed: added all `/auth/*` paths to
   `PUBLIC_API_PATHS`.
2. **Users table missing email column** — inline migration couldn't apply the
   full schema on an existing table. Fixed: idempotent `ALTER TABLE`
   statements.
3. **`wallet_address` NOT NULL constraint** — email-based registration has no
   wallet address. Fixed: made the column nullable.
4. **Fhenix encrypt endpoint not public** — `/fhenix/encrypt` was missing from
   `PUBLIC_API_PATHS`.
5. **Metrics ux-events not public** — `/metrics/ux-events` (POST) was missing
   from `PUBLIC_API_PATHS`.
6. **MCP governance-check not public** — `/mcp/governance-check` was missing.
7. **Sealed-bid sub-paths not public** — only `/vendor/sealed-bid/rounds` was
   listed; fixed with parameterized path matching in
   `isPublicApiPath()`.
8. **Projects sub-paths not public** — `/projects/:projectId/usage` and
   `/projects/:projectId/tokens` were missing.
9. **Speech transcription not public** — `/speech/transcribe` was missing.
10. **Sealed-bid reveal not fully implemented** — returns 400 because "threshold
    decryption of real CoFHE bids is not yet wired." Documented as a known
    limitation, not a bug to fix.
11. **Sapience agent status 500** — "sapience" was missing from the
    `demoAgentNames` map in `AgentsController`.
12. **CRE projects 404** — the route was defined as `/projects` in
    `miscRoutes.ts`, not `/cre/projects`. Fixed by adding alias routes.
13. **`OwsWalletController.createAgent` / `OwsApiKeyController.createApiKey`
    crash** — both threw `BadRequestError` without try/catch, causing
    unhandled promise rejections (502).
14. **`OwsWalletController.getWallet/importWallet/connectExternal` crash** —
    same unhandled-throw pattern.
15. **`OwsApiKeyController.getApiKey/deleteApiKey` crash** — same pattern.
16. **`OwsPermissionsController` all methods crash** —
    `requestPermissions`, `getPermissions`, `revokePermissions`,
    `checkPermissions` all threw without try/catch.
17. **Workspaces table missing `settings` column** —
    `WorkspaceController.getWorkspace` queries `settings` but the column
    didn't exist, causing `SqliteError`.

These bugs fell into two categories: public endpoints that were gated by the API-key
middleware (1–9), and unhandled errors that crashed the server when caught outside a
route handler (10–17). Server-side hardening — stop on `unhandledRejection`, wrap
